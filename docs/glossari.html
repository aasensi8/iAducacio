Glossari

Conceptes clau d’intel·ligència artificial, explicats amb claredat i ordenats alfabèticament.

Al·lucinacióAprenentatge profundLLMPromptXarxa neuronal

Al·lucinació

Una resposta generada per una IA que presenta com a real una afirmació falsa o no fonamentada. Pot semblar convincent; cal contrastar-la amb fonts fiables.

Exemple: Un assistent inventa una referència bibliogràfica que no existeix.

Font: Google for Developers · Machine Learning Glossary.

Aprenentatge profund

Part de l’aprenentatge automàtic que utilitza xarxes neuronals amb diverses capes per aprendre patrons a partir de dades.

Exemple: Un model aprèn patrons en imatges per identificar objectes.

Font: Google for Developers · Machine Learning Glossary.

LLM

Un model de llenguatge de grans dimensions (large language model) és un model entrenat amb grans quantitats de dades que pot generar i processar llenguatge. Un assistent és el servei que permet interactuar amb un model.

Exemple: Un LLM pot generar un resum o respondre una pregunta; les respostes s’han de revisar.

Font: Google for Developers · Machine Learning Glossary.

Prompt

Text amb què indiquem a un model d’IA què volem que faci; pot incloure una pregunta, una instrucció, context o exemples.

Exemple: «Explica la fotosíntesi per a 2n d’ESO amb un exemple.»

Font: Google for Developers · Machine Learning Glossary.

Xarxa neuronal

Model computacional format per unitats connectades, organitzades habitualment en capes, que transforma dades d’entrada en resultats. Durant l’entrenament, ajusta els paràmetres de les connexions.

Exemple: Una xarxa pot aprendre a distingir sons a partir d’exemples.

Font: Google for Developers · Machine Learning Glossary.
