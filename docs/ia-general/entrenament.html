DADES, AJUST I COMPROVACIÓ

Com s’entrena?

Entrenar un model d’aprenentatge automàtic consisteix a ajustar-ne els paràmetres per millorar el resultat respecte d’un objectiu. Les dades, l’objectiu i el procés d’avaluació condicionen què aprèn i on pot fallar. [3] [6]

Entrenament

Exemples amb què s’ajusten els paràmetres del model.

Validació

Dades per comparar configuracions i guiar decisions de desenvolupament.

Prova

Dades reservades per a l’avaluació final del model seleccionat.

No hi ha un percentatge universal per a cada conjunt. Cal evitar duplicats i filtracions entre conjunts. [6]

En el cas dels LLM

  1. Preentrenament: aprenentatge de patrons lingüístics mitjançant tasques com predir tokens. [5]
  2. Ajust posterior: entrenament addicional per seguir instruccions o adaptar-se a una tasca. Les tècniques concretes varien entre models. [5] [7]
  3. Avaluació: comprovar resultats amb exemples diferents dels usats per ajustar el model. [6]
Una conversa no equival a reentrenar el model

Donar instruccions o exemples en un prompt orienta la resposta mitjançant el context, sense modificar per si mateix els paràmetres. El possible ús posterior de converses pel proveïdor és una qüestió diferent, regulada per les seves condicions. [7]

Maneres d’aprendre

Els sistemes d’IA poden aprendre de maneres diferents segons les dades i els senyals que reben.

Supervisat

Aprèn a partir d’exemples amb resultats coneguts, com dades etiquetades. [3]

No supervisat

Explora estructures o agrupacions sense una resposta etiquetada per a cada exemple. [3]

Autosupervisat

Construeix el senyal d’aprenentatge a partir de les mateixes dades, com en la predicció de tokens. [5]

Per reforç

Ajusta el comportament a partir de senyals de recompensa vinculats a les accions. [3]
