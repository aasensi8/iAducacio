Glosario

Conceptos clave de inteligencia artificial, explicados con claridad y ordenados alfabéticamente.

AlucinaciónAprendizaje profundoLLMPromptRed neuronal

Alucinación

Respuesta generada por una IA que presenta como real una afirmación falsa o sin fundamento. Puede parecer convincente; conviene contrastarla con fuentes fiables.

Ejemplo: Un asistente inventa una referencia bibliográfica inexistente.

Fuente: Google for Developers · Machine Learning Glossary.

Aprendizaje profundo

Parte del aprendizaje automático que utiliza redes neuronales con varias capas para aprender patrones a partir de datos.

Ejemplo: Un modelo aprende patrones en imágenes para identificar objetos.

Fuente: Google for Developers · Machine Learning Glossary.

LLM

Un modelo de lenguaje de gran tamaño (large language model) es un modelo entrenado con grandes cantidades de datos que puede generar y procesar lenguaje. Un asistente es el servicio que permite interactuar con un modelo.

Ejemplo: Un LLM puede generar un resumen o responder una pregunta; sus respuestas deben revisarse.

Fuente: Google for Developers · Machine Learning Glossary.

Prompt

Texto con el que indicamos a un modelo de IA lo que queremos que haga; puede incluir una pregunta, una instrucción, contexto o ejemplos.

Ejemplo: «Explica la fotosíntesis para 2.º de ESO con un ejemplo.»

Fuente: Google for Developers · Machine Learning Glossary.

Red neuronal

Modelo computacional formado por unidades conectadas, organizadas habitualmente en capas, que transforma datos de entrada en resultados. Durante el entrenamiento ajusta los parámetros de las conexiones.

Ejemplo: Una red puede aprender a distinguir sonidos a partir de ejemplos.

Fuente: Google for Developers · Machine Learning Glossary.
