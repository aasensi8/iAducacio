Glossary

Key artificial intelligence concepts, clearly explained and listed alphabetically.

Deep learningHallucinationLLMNeural networkPrompt

Deep learning

A branch of machine learning that uses neural networks with multiple layers to learn patterns from data.

Example: A model learns patterns in images to identify objects.

Source: Google for Developers · Machine Learning Glossary.

Hallucination

An AI-generated response that presents a false or unsupported claim as factual. It can sound convincing, so check it against reliable sources.

Example: An assistant invents a bibliographic reference that does not exist.

Source: Google for Developers · Machine Learning Glossary.

LLM

A large language model is a model trained on large amounts of data that can generate and process language. An assistant is a service that lets people interact with a model.

Example: An LLM can produce a summary or answer a question; its output needs checking.

Source: Google for Developers · Machine Learning Glossary.

Neural network

A computational model made of connected units, usually arranged in layers, that transforms inputs into outputs. During training, it adjusts the parameters of its connections.

Example: A network can learn to distinguish sounds from examples.

Source: Google for Developers · Machine Learning Glossary.

Prompt

Text used to tell an AI model what to do; it can include a question, instruction, context or examples.

Example: “Explain photosynthesis to a 13-year-old using an example.”

Source: Google for Developers · Machine Learning Glossary.
